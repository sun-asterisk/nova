Sun* Design System はプロダクト開発における一貫性あるデザインと高品質なユーザー体験を実現するためのデザインシステムライブラリです。

このガイドでは、ファイル構成、基本ルール、プロジェクト適用手順、Tips、よくある質問までをまとめています。<br />
使用上の注意をよく読み、ガイドを守って正しくお使いください。
