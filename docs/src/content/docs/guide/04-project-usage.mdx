## プロジェクトへの利用手順

### Sun\* 環境で Figma を管理する場合

#### ファイルの複製

はじめにこのライブラリファイルを複製し、複製したファイルのファイル名を編集してください。

#### ファイルの移動

1. 複製したファイルのメニューから「ファイルを移動…」を選択
2. 移動先のチームを選択し、「移動」を押して完了

#### 共有先および権限を設定

必要に応じて、リンクの共有や編集・閲覧権限の付与を行なってください。

### クライアント環境で Figma を管理する場合

#### ファイルの複製

はじめにこのライブラリファイルを複製し、複製したファイルのファイル名を編集してください。

#### ファイルの移動

1. 複製したファイルを開き、\[ファイル\] > \[ローカルコピーの保存\] を選択してダウンロード
2. インポートする Figma アカウント / プロジェクトを開き、1の「.fig」ファイルをドラッグ

#### 共有先および権限を設定

必要に応じて、リンクの共有や編集・閲覧権限の付与を行なってください。

## ライブラリの有効化

移動したデザインシステムの「ライブラリ管理」よりライブラリを**公開**します。異なるファイルまたはプロジェクトをまたがって再利用可能な状態となります。

![「ライブラリ管理」の「このファイルで作成されたアセット」に表示された Sun* Design System と「公開…」ボタン](/assets/guide/project-usage/library-publish.png)

利用したいデザインファイルを開き、「ライブラリ管理」より公開したライブラリを**追加**します。

## Foundation の定義

デザイン原則やコンセプトに従って Foundation を定義します。プロダクトのブランドカラーやタイポグラフィに応じて、必要な部分を調整してください。

## Components の定義・調整

ボタン、入力フォームなどの基本UIを、プロダクト仕様に合わせてカスタマイズします。<br />
不足しているコンポーネントは、ライブラリにある設計思想やフォーマットを参考にして作成してください。

## Icons の作成・調整

アイコンも一貫性を持って設計しましょう。<br />
基準となる線の太さや角丸など、プロダクトのトンマナに合わせて定義したうえで作成してください。
