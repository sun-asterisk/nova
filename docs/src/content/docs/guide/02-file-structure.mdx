## ライブラリの構成

### Foundations

色、タイポグラフィ、スペーシング、エレベーションなど、デザインの基礎ルール

### Components

ボタン、入力フォーム、ラジオボタンなど、共通で使用できるコンポーネント群

### Icons

アイコン制作ガイドおよびプロダクト内で使用できる標準アイコンセット

### Support

デザイン仕様やドキュメント整理などで活用できる、ツールキット
