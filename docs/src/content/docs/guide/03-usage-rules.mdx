## 本ライブラリは直接編集できません

プロジェクト等で利用する際は、必ず複製してから作業するようにしてください。<br />
※ 詳しくは「[プロジェクトでの利用方法](/guide/04-project-usage/)」をご確認ください

## 重要

このデザインシステムは直接プロジェクトに流用しないことを原則とします。プロジェクトのトンマナに合わせたビジュアル調整は適宜行ってください。

※ 仮説検証フェーズやデザインコンセプトがまだ定まっていない場合であれば、そのまま使用しても構いません

また、品質と一貫性を保つため、**ファイルの構成、レイアウトや情報量を意図なく大きく変えない**でください。

## 命名規則

**英語表記 + PascalCase（単語の先頭を大文字）**

- 単語の先頭を大文字にし、英小文字のみや日本語の命名は避け、「意味が通る最小単位」で簡潔につけてください。（例：ButtonPrimary）
- BtnやTxtなどの略語使わず Button, Text に統一してください。
- バリエーションが発生する場合はスラッシュ区切りで管理します。（例：Button / Primary）

## レイヤー命名の重要性

**Figmaの共同作業において、構造や役割、階層がひと目でわかる名前をつけることには、次のようなメリットがあります。**

- **他のメンバーがすぐに構造を理解できる**
- **検索・再利用がしやすくなる**
- **引き継ぎやレビューがスムーズに進む**

「自分以外の人もこのファイルを見る」という視点を持ち、**他者への配慮を意識すること**が重要です。
