## ガイドライン

### 設計の原則

モーダルは、ユーザーの操作フローを意図的かつ一時的に「中断」させるという強力な機能です。重大な確認や、コンテキストを離れずに完了できる短いタスクなど、その中断が明確に正当化される場合にのみ使用できます。

背景をスクリムで覆うことで、モーダル内での判断や操作に集中できるようにし、タスクが完了するかキャンセルされたら、即座に元のフローに戻れるように設計します。

タイトルは、モーダルの目的を簡潔に示すよう原則 1行とし、長くても2行以内に収めてください。

![スクリム上に中央表示されたモーダルの基本形](/assets/components/modal/g2-1.png)

### 用途と使い分け

**推奨される用途**

- **重大な確認**
  - ユーザーの操作が元に戻せない、または重大な結果を伴う場合の最終確認。
- **コンテキストを保持したタスクの完了**
  - 現在のページから離れずに、独立したタスクを完了させる必要がある場合。
- **追加情報の表示**
  - コンテキストを離れずに、補足情報や詳細を提示する場合。

<Aside type="tip">
ユーザーに実行させるアクションがなく、情報の閲覧のみが目的の場合は、フッター自体を省略することを推奨します。フッターに「閉じる」ボタンを設置する必要はありません。
</Aside>

**アンチパターン**

- **重要でない通知**
  - エラーメッセージや成功の通知など、一時的で重要度が低いフィードバックには使用しません。Snackbar を使用してください。
- **関連コンテンツへの導線**
  - 関連ページへのリンクなど。ドロップダウンメニューやインラインリンクを使用してください。

**Do** 重要な操作の意図を明確に確認する場合に使用する ／ **Don't** 重要度が低いフィードバックに使用する

![Do: 重要な操作の意図を明確に確認する場合に使用する / Don't: 重要度が低いフィードバックに使用する](/assets/components/modal/g2-2.png)

**Do** 1画面で完結し、背景とのコンテキストを保った軽量な作業フローに使用する ／ **Don't** モーダル内で別ページへのリンクを羅列する

![Do: 1画面で完結する軽量な作業フローに使用する / Don't: モーダル内で別ページへのリンクを羅列する](/assets/components/modal/g2-3.png)

**Do** 関連情報を補足して、判断を助ける場合に使用する ／ **Don't** ×ボタンと閉じるボタンを併用している

![Do: 関連情報を補足して判断を助ける場合に使用する / Don't: ×ボタンと閉じるボタンを併用している](/assets/components/modal/g2-4.png)

### アクションボタンの配置

アクションボタンはフッターの右側に配置します。肯定的なアクションと否定的なアクションの2つを基本とし、肯定的なアクションは右側、否定的なアクションは左側に配置します。

「下書き保存」など、3つ目の選択肢が必要な場合のみ、最大3つまでの配置を許容します。その場合は3つ目の選択肢をフッターの左側に配置してください。

<Aside type="tip" title="例外ケース">
ユーザーに選択や意思決定を求めるのではなく、タスクの完了報告など、内容の確認・承認のみを目的とする場合に限り、否定的なアクションは不要とし、フッターには「OK」や「確認しました」といった承認用のアクションボタンを1つだけ配置することを許可します。

この場合、機能が重複するヘッダーの「閉じるボタン」は省略します。
</Aside>

![アクションボタンの配置例（3つ目の選択肢あり／肯定的なアクションのみ（×ボタンの省略）／アクションボタンなし）](/assets/components/modal/g2-5.png)

### 表示と制御

- **表示**
  - モーダルの表示に合わせて背景のページ全体がスクリムで覆われ、背景ページのスクロールはロックされます。
    背景のページ情報にブラー効果は適用しません。
- **閉じる方法**
  - アクションボタンをクリック
  - ヘッダーの閉じるボタンをクリック
  - モーダル外側のスクリムをクリック
  - キーボードの Escape キーを押す
- **モーダルの重複**
  - モーダルの上にさらに別のモーダルを重ねて表示することは、ユーザーの混乱を招くため原則禁止します。フローが複雑になる場合は、ページ遷移やモーダル内でのステップ表示を検討してください。

<Aside type="tip" title="例外ケース">
以下のケースでは、意図しない離脱を防いだり、ユーザーのアクションを明確にしたりするために、「閉じるボタン」と「スクリムクリック」を無効化（非表示に）することを推奨します。

- 重大な確認：削除など、ユーザーに明確な意思決定を強制させたい場合。
- 承認モーダル：配置とレイアウトの例外ルールに基づき、フッターに「OK」ボタンのみを配置し、そのボタンでの確認を促す場合。
</Aside>

**Don't** 背景のページ情報にブラー効果を適用する ／ **Don't** モーダルの上にさらに別のモーダルを重ねて表示する

![Don't: 背景のページ情報にブラー効果を適用する / Don't: モーダルの上にさらに別のモーダルを重ねて表示する](/assets/components/modal/g2-6.png)

## デザイン仕様

### 配置

モーダルは常に、ビューポートの中央（垂直・水平方向）に配置されます。

![ビューポート中央（垂直・水平方向）への配置仕様](/assets/components/modal/g3-1.png)

### サイズ

![モーダル内部の余白仕様（ヘッダー・コンテンツ・フッターの各余白、Elevation Lv.5）](/assets/components/modal/g3-2.png)

### 横幅

- Small：384px
- Medium：560px （デフォルト）
- Large：768px

![横幅のバリエーション（Small 384 / Medium 560 / Large 768）](/assets/components/modal/g3-3.png)

### 高さ

- Auto（コンテンツ量に応じて可変）
- Max-height：画面上下に80pxのマージンを確保

![高さの仕様（Auto・Max-height 時は画面上下に 80px のマージン）](/assets/components/modal/g3-4.png)

### スクロール

モーダルのコンテンツが Max-height を超えた場合、ヘッダーとフッターは常に固定表示され、本文エリアのみでスクロールが発生します。

コンテンツがスクロール可能であることをユーザーに視覚的に伝えるため、コンテンツが隠れている側に区切り線を動的に表示します。

- **スクロールが不要な場合**
  - 区切り線は一切表示しません
- **スクロールが必要な場合（初期状態）**
  - フッターの上にだけ、区切り線を表示
- **スクロール中（中間）**
  - ヘッダーの下とフッターの上の両方に区切り線を表示
- **スクロールが一番下に到達した場合**
  - フッターの上の区切り線は消え、ヘッダーの下の区切り線だけが残る

![スクロール状態ごとの区切り線の表示仕様](/assets/components/modal/g3-5.png)

## React での使い方

```tsx
import {
  Modal, ModalTrigger, ModalContent, ModalHeader, ModalTitle, ModalBody, ModalFooter, ModalClose,
} from '@sun-asterisk/nova/modal';

<Modal>
  <ModalTrigger asChild><Button>削除する</Button></ModalTrigger>
  <ModalContent status="danger">
    <ModalHeader><ModalTitle>プロジェクトを削除しますか？</ModalTitle></ModalHeader>
    <ModalBody>この操作は取り消せません。</ModalBody>
    <ModalFooter>
      <ModalClose asChild><Button variant="secondary">キャンセル</Button></ModalClose>
      <Button variant="danger">削除</Button>
    </ModalFooter>
  </ModalContent>
</Modal>
```

- **幅（`ModalContent` の `size`）** — `small`（384px）/ `medium`（560px・既定）/ `large`（768px）/ `auto`（内容に合わせる）
- **ステータスアイコン（`status`）** — Figma の「+ Status Icon」。タイトルの前に 24px の [StatusIcon](/components/status-icon/) を表示し、本文とフッターをタイトルの位置に揃えます
- **背景** — `ModalContent` が [Scrim](/components/scrim/) と同じ背景を自動で表示します。自分で `Scrim` を置く必要はありません
- **スクロール** — `ModalBody` の内容があふれると、[Scrollbar](/components/scrollbar/) 内でスクロールし、上下の区切り線が表示されます
- 閉じるボタンの読み上げ名は `ModalHeader` の `closeLabel`（既定 `'Close dialog'`）で変更できます
