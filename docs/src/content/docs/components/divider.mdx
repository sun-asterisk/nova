<p class="comp-lead">ディバイダーは、異なるセクションやコンポーネント、またはコンテンツのグループ間に配置される視覚的な区切りです。これにより、要素同士の関係性を整理し、コンテンツが視覚的に区分けされ、読みやすさや視認性が向上します。</p>

![Divider のバリエーション一覧](/assets/components/divider/showcase.png)

## ガイドライン

### 種類と使い分け

ディバイダーは、コンテンツの区切り方に応じて 全幅 と 部分幅 の2種類を使い分けます。

全幅は、ページや大きなセクションの区切りに適用し、コンテナや画面の横幅いっぱいに広がります。
部分幅は、カードやコンポーネント内の区切りに使用し、テキストやコンポーネントに合わせて適切な幅で配置します。

![全幅ディバイダーの使用例（メニューのセクション区切り）](/assets/components/divider/g2-1.png)

**全幅** セクション全体の区切りや複数のリストアイテムの分割など、視覚的に強い区切りを求める場面で使用します

![部分幅ディバイダーの使用例（カード内の見出し下の区切り）](/assets/components/divider/g2-2.png)

**部分幅** カードやモジュール内の区切り、見出しの下の短めの装飾的な区切りなど、強調しすぎず、コンテンツのグループ化をサポートする場面で使用します

### 配置

ディバイダーを配置する際は、隣接するテキストやコンテンツと十分な間隔を設け、区切りの役割を明確にし、窮屈さを防ぎます。

![ディバイダーの上下に余白を確保した Do の例](/assets/components/divider/g2-3.png)

**Do** ディバイダーの上下には、最低でも8px以上のスペースを確保

![リスト間に余白がない Don't の例](/assets/components/divider/g2-4.png)

**Don't** 各リストの間に余白がなく、圧迫感がある
