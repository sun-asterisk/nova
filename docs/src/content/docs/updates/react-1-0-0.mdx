<Aside type="note" title="バージョン番号について">
これは **React パッケージ**（`@sun-asterisk/nova`）のバージョンです。[Figma ライブラリ](/updates/2026-10-09-figma-1-0-0/)とは別に番号を付けています。
</Aside>

## 公開

Nova の Figma ライブラリを実装した React コンポーネントライブラリを公開しました。導入方法は[インストール](/guide/08-installation/)を参照してください。

## 含まれるもの

- **コンポーネント:** Avatar, Badge, Button（Icon Button を含む）, Checkbox, DatePicker / Calendar, Divider, DropdownMenu, Input / TextField, Textarea / TextareaField, Link, Modal, ProgressBar, RadioGroup, Scrim, Scrollbar, Snackbar, Spinner, StatusIcon, Switch, Tabs, Tooltip（[コンポーネント一覧](/components/)）
- **アイコン:** 61 種（`@sun-asterisk/nova/icons`）
- **テーマ:** ThemeProvider（ライト / ダーク / システム、領域ごとのテーマ）とデザイントークンの CSS 変数（[テーマとリブランド](/guide/09-theming/)）
- **Figma Code Connect:** Figma の Dev Mode で、各コンポーネントの実際の React コードを参照できます（[Code Connect](/guide/10-code-connect/)）
- **フォーム連携:** React Hook Form などと組み合わせる方法をまとめています（[フォーム](/guide/11-forms/)）
